PLANNEX

Smart Study Planning Platform built with Django, WebSocket, Google OAuth & Razorpay.

View on GitHub
📘 PLANNEX
Overview - Plannex stands for "Plan & Execute". It is a Smart Study Planning System developed to help students identify their weak academic areas and improve them through a structured and personalized study plan. The system supports students, tutors, parents, and administrators by providing a comprehensive and efficient learning experience.
Core Modules
Student Module – Helps students access study resources, attend online exams, view performance graphs, and follow personalized study plans. Students can also communicate with tutors through the chat system and receive important notifications.
Tutor Module – Allows tutors to manage students, provide study materials, conduct exams, share online class links, and monitor student performance. Tutors can also interact with students to clear doubts and guide their learning process.
Parent Module – Enables parents to monitor the academic progress of their children. Parents can view performance reports, exam results, and weak subject areas to support their child's educational development.
Admin Module – Manages the overall system activities. Administrators can manage users, send notifications, monitor platform operations, and ensure smooth functioning of the entire system.
Technologies Used
Frontend: HTML, CSS, Bootstrap, JavaScript
Backend: Python, Django Framework
Database: SQLite
Real-Time Communication: Django Channels, WebSockets, Daphne (ASGI Server)
Payment Integration: Razorpay
Operating System: Windows Operating System
Development Tools: Visual Studio Code, SQLite Database Browser
Key Features
Weak subject identification
Personalized study planning
Priority-based learning recommendations
Online examinations
Study resource management
Performance graphs and progress tracking
Real-time chat for doubt clarification
Online class link sharing
Live notification system
Parent monitoring module
Secure online payment using Razorpay
System Working
Students register and access the platform.
Tutors provide study materials, conduct exams, and share class links.
Students attend exams and use available learning resources.
The system analyzes academic performance and identifies weak subjects.
Based on the analysis, a priority-based study plan is generated.
Students communicate with tutors through real-time chat for doubt clarification.
Parents monitor their child's academic progress through the Parent Module.
Administrators manage users, notifications, and overall system operations.
Plannex helps students plan their studies effectively, execute their learning goals efficiently, and improve academic performance through continuous monitoring and guidance.

Legal Advisory Web App using Python, Django, Bootstrap & MySQL.

⚖️ ASESORA LEGAL
Overview - ASSESORA LEGAL is a web-based legal assistance and lawyer management platform that connects users with qualified advocates through a centralized online system. The platform enables users to search for lawyers based on their specialization, ratings, experience, and fees, making it easier to find suitable legal support.
Technologies Used - Frontend: HTML5, CSS3, JavaScript, Bootstrap, jQuery, AJAX • Backend: Python & Django Framework • Database: MySQL
Development Tools - Visual Studio Code (VS Code)
Operating System - Windows 10/11
Features
User registration and login. Advocate registration and admin verification.
Search lawyers based on specialization, ratings, and fees. View lawyer profiles and qualifications.
Post legal cases with descriptions and supporting images. Request lawyers for legal representation.
Appointment booking and management.
Chat and communication between users and lawyers.
View and search IPC sections for legal awareness.
Working of the System
Users and advocates register on the platform. The administrator verifies and approves advocate registrations.
Users log in and search for lawyers according to their legal requirements. Users can post case details and request legal assistance.
Lawyers view available cases and send requests to represent users. Appointments can be scheduled through the platform.
Users and advocates communicate through the integrated chat feature. Administrators monitor system activities, manage users and lawyers, review feedback, and maintain IPC section information.
The system provides a convenient and transparent platform for accessing legal services online.
