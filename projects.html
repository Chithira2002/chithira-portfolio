📊 Winlog
Overview – WinLog is a comprehensive management and tracking system designed to streamline business operations by providing a centralized platform for recording, monitoring, and managing project-related information.
Technologies Used – Frontend: HTML5, CSS3, JavaScript, Bootstrap • Backend: Python & Django • Database: SQlite
Development Tools – Visual Studio / Visual Studio Code
Operating System – Windows 10 / Windows 11
Key Features
Centralized project data management
User authentication with role-based access
Real-time activity tracking
Interactive dashboard with key metrics
Data entry, editing, and record maintenance
Advanced search and filtering
Automated report generation and export
Notification and alert management
Complete audit trail for user actions
Secure data storage and backup
Responsive, user-friendly interface
Enhanced team collaboration
Working of the System – The WinLog system operates through a centralized platform where authorized users can securely log in and access project-related information based on their roles and permissions. Users can create, update, and manage records, while the system stores all data in a centralized database for easy retrieval and monitoring. The application tracks activities in real time, maintains data accuracy, and provides dashboards and reports for analyzing progress and performance. Administrators can oversee system operations, manage user access, and generate reports, enabling efficient decision-making and improved operational control across the organization.

📦 Inventory Management
Overview – The Inventory Management System is a web-based application designed to manage and monitor inventory operations efficiently. The system allows users to maintain item records, add stock through Goods In transactions, remove stock through Goods Out transactions, and track current inventory levels. It also manages expiry dates for perishable products and provides various reports such as Stock Reports, Expired Items Reports, Low Stock Reports, Goods In Reports, and Goods Out Reports. The system helps organizations maintain accurate inventory records, reduce stock losses, and improve inventory control.
Technologies Used – Python • Django Framework • HTML5 • CSS3 • SQLite Database
Development Tools – Visual Studio Code (VS Code)
Operating System – Windows 10 / Windows 11
Key Features
Add, Edit, Delete, and Search Items
Goods In (Stock Entry)
Goods Out (Stock Issue)
Automatic Stock Calculation
Expiry Date Management
Dashboard with Statistics
Stock Report Generation
Expired Items Report
Low Stock Report
Goods In Report
Goods Out Report
User-Friendly Interface
Working of the System – The system begins with the creation of inventory items through the Master Item module. When stock is received, users record the quantity using the Goods In module. When products are issued or sold, the quantity is recorded through the Goods Out module. The system automatically calculates the available stock by subtracting issued quantities from received quantities while excluding expired items. Users can view real-time inventory status through the dashboard and generate various reports to monitor stock availability, expired products, low-stock items, and inventory transactions.
